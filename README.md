# Прогнозирование оттока клиентов (Customer Churn Prediction)

## Описание проекта

Цель проекта — прогнозирование оттока клиентов интернет-магазина с помощью методов машинного обучения.

Прогнозирование оттока помогает компании заранее выявлять клиентов, которые могут перестать пользоваться её услугами, и принимать меры для их удержания.

## Датасет

В проекте используется датасет E-Commerce Customer Churn с платформы Kaggle.

Исходный Excel-файл не загружен в репозиторий.

Для запуска проекта необходимо:

1. Скачать датасет с Kaggle.
2. Создать в папке проекта каталог `data`.
3. Поместить файл `E Commerce Dataset.xlsx` в папку `data`.
В рамках EDA выполнены:

- Изучение структуры данных и описательной статистики.
- Анализ и обработка пропущенных значений.
- Проверка дубликатов и выбросов.
- Анализ распределения целевой переменной Churn.
- Анализ взаимосвязей между признаками.
- Построение графиков и сводных таблиц.
- Формулирование выводов по результатам анализа.
Ссылка на датасет: [Kaggle](https://www.kaggle.com/datasets/ankitverma2010/ecommerce-customer-churn-analysis-and-prediction)
